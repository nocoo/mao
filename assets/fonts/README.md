# 本地中文字体

这里的 WOFF2 均为 Google Fonts 官方 `text` API 返回的子集原文件，未再修改字形或字体名称。页面只加载同目录本地文件，不依赖 CDN。

## 家族与用法

- `font-family: 'Noto Serif SC'`：正文、诗词、注释和界面；CSS 暴露可变字重 **400–600**（`font-weight: 400 600`）。官方二进制的实际 `wght` 轴可能更宽，见下表；均完整覆盖 400 与 600 及中间字重。
- `font-family: 'Ma Shan Zheng'`：刊头书法；静态 **400**。
- 两家族均为 `font-style: normal`、`font-display: swap`，保留官方返回的 `unicode-range`；不使用 `local()` 或外部 URL。
- 入口引用：`<link rel="stylesheet" href="assets/fonts/fonts.css">`；字体路径相对该 CSS 解析。

## 字形覆盖与批次

- 采集范围：递归读取 `data/**/*.md` 的 **107** 个文件（含诗词、注释、题解、版本资料及原始来源全文）、当次 [index.html](../../index.html)，再加下列 UI 种子；按 Unicode 码点去重。不仅采集诗词标题。
- 排除换行、制表及其他 Unicode 控制字符；保留可见符号及排版空白，并补足 U+0020–U+007E 可打印 ASCII（含数字）。
- Noto 共请求 **2,689 个码点**，其中 **2,538 个汉字**。首片包含 ASCII、所有非汉字符号及当前 HTML/UI 文字（419 个码点）；其余按码点排序，最多 **500 个字符**一批，共 **6 片**。
- Ma Shan Zheng 请求 **37 个刊头字**：`一万上下为主今偶入卷墨多如娇展山岁席成日月朱此毛江河生笔纸词诗读赏里鉴风骨`。此字体不用于全篇正文。

## 验证

- 所有字体均验证 `wOF2` 文件签名与 WOFF2 头部声明长度；解码后读取 `cmap`、`maxp`，并检查 Noto 每片的 `fvar` 轴覆盖 400–600。
- 所有当前语料汉字与刊头字均在相应字体 `cmap` 中；CSS 的每个 `src` 都指向已存在的本地 WOFF2。
- 官方 Noto 子集不提供以下非汉字码点；这些符号由页面的系统字体回退显示（不影响诗词与注释汉字）：`U+2726 ✦`。
- 新增诗文或界面文字后，需重新采集并下载子集；本目录不是完整中文字库。
